# Drum pack sources

These are unchanged Hydrogen `.h2drumkit` archives downloaded from the
[official Hydrogen sound-library archive](https://sourceforge.net/projects/hydrogen/files/Sound%20Libraries/Main%20sound%20libraries/).
Each archive contains its original `drumkit.xml` metadata and any license file
distributed with the kit.

- `Boss_DR-110.h2drumkit`
- `Classic-626.h2drumkit`
- `Classic-808.h2drumkit`
- `ColomboAcousticDrumkit.h2drumkit`
- `EasternHop-1.h2drumkit`
- `ElectricEmpireKit.h2drumkit`
- `ErnysPercussion.h2drumkit`
- `HardElectro1.h2drumkit`
- `HipHop-1.h2drumkit`
- `HipHop-2.h2drumkit`
- `Techno-1.h2drumkit`
- `TR808909.h2drumkit`
- `YamahaVintageKit.h2drumkit`

Fifty selected one-shots from ten of the packs are converted to browser-safe
44.1 kHz PCM WAV files under `public/audio/drums`. The complete archives stay
here so more sounds and procedural patterns can be added without another
download.
