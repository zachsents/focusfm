# Ready-made drum loop sources

The original MP3 downloads in this directory come from
[Orange Free Sounds](https://orangefreesounds.com/category/loops/drum-loops/).
The source pages label the loops as Creative Commons Attribution 4.0 and free
for commercial use. Browser copies under `public/audio/drum-loops` are decoded
to 44.1 kHz PCM WAV and trimmed to an exact musical length so they repeat and
time-stretch without encoder-padding drift.

- `77-bpm.mp3` — [77 BPM drum loop](https://orangefreesounds.com/77-bpm-drum-loop/), Alexander
- `downbeat-86.mp3` — [86 BPM downbeat drum loop](https://orangefreesounds.com/86-bpm-downbeat-drum-loop/), Alexander
- `percussion-95.mp3` — [Drum and percussion loop](https://orangefreesounds.com/drum-percussion-loop/), Patchen
- `electronic-96.mp3` — [96 BPM drum loop](https://orangefreesounds.com/96-bpm-drum-loop/), Alexander
- `breakbeat-106.mp3` — [106 BPM drum loop](https://orangefreesounds.com/drum-loop-106-bpm/), Alexander
- `electronic-111.mp3` — [Electronic drum loop](https://orangefreesounds.com/free-electronic-drum-loop/), Alexander
- `hip-hop-120.mp3` — [120 BPM hip-hop drum loop](https://orangefreesounds.com/120-bpm-hip-hop-drum-loop/), Alexander
- `kaoss-124.mp3` — [124 BPM drum loop](https://orangefreesounds.com/drum-loop-124-bpm/), Alexander
- `percussion-135.mp3` — [135 BPM percussion loop](https://orangefreesounds.com/drum-loop-percussions-135-bpm/), Alexander
